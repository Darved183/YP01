## KeptShop

KeptShop — сайт магазина одежды, где покупка проходит весь путь: от каталога до заказа, готового к выдаче. Гость только смотрит вещи, клиент собирает корзину и оформляет заказ, и склад уменьшается именно в этот момент, а менеджер с администратором дальше ведут заказ по статусам и подтверждают каждую смену.

## Docker

Из корня проекта:
```
docker compose up -d --build
```
Сайт открывается на http://127.0.0.1:8181.

Остановить контейнер: 
```
docker compose down
```

## Локально на машине

Нужен Go 1.26.

Запуск:

```
go run ./cmd/app
```

Сайт: http://localhost:8181. База создаётся в файле `db.db` рядом с программой.

## curl запросы

Список товаров
`curl "http://127.0.0.1:8181/product?page=1&limit=10&sort=price&order=desc"`

Определенный товар
`curl http://127.0.0.1:8181/product/c0000000-0000-4000-8000-000000000001`

Новый товар
```
curl -Method Post http://127.0.0.1:8181/product `
  -Headers @{"Content-Type"="application/json"} `
  -Body '{"name":"Жилет","type":"Жилет","gender":"женский","size":"M","color":"оливковый","description":"Короткий жилет","brand":"FORMA","season":"демисезон","price":1990,"stock":3}'
  ```

Удалить товар
`curl -Method Delete http://127.0.0.1:8181/product/{UUID товара}`

Список ролей
`curl http://127.0.0.1:8181/role`

Новая роль 
```
curl -Method Post http://127.0.0.1:8181/role `
  -Headers @{"Content-Type"="application/json"} `
  -Body '{"name":"Курьер"}'
```

Удалить роль
`curl -Method Delete http://127.0.0.1:8181/role/СЮДА-ID`

Новый пользователь 
```
curl -Method Post http://127.0.0.1:8181/user `
  -Headers @{"Content-Type"="application/json"} `
  -Body '{"name":"Иван","email":"ivan@forma.test","phone":"+7 900 000-00-00","role_id":"00000000-0000-0000-0000-000000000002"}'
```

Изменить пользователя
```
curl -Method Put http://127.0.0.1:8181/user/b0000000-0000-4000-8000-000000000001 `
  -Headers @{"Content-Type"="application/json"} `
  -Body '{"name":"Анна Соколова","email":"client@forma.test","phone":"+7 900 111-22-33","role_id":"00000000-0000-0000-0000-000000000002"}'
```

Удалить пользователя
`curl -Method Delete http://127.0.0.1:8181/user/{UUID пользователя}`

Список заказов
`curl "http://127.0.0.1:8181/order?page=1&limit=10&status=Принят&start=2026-09-01T00:00:00&end=2026-09-30T23:59:59"`

и др.


## Реализация

В данном проекте реализован полный функционал согласно ТЗ.
Однако есть нюансы

В Backend реализованы endpoint для удаления и создания ролей, однако на front это было не добавлено,
однако на Frontend это не получило нужной реализации за ненадобностью.

Такую же судьбу настигла и пагинация, т.к. современные дизайнерские решения уходят от этого метода, 
однако, если потребуется, то можно быстро исправить, т.к. данный функционал backend предусматривает
